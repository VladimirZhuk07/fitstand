# Опрос, каталог видов и справочник узлов — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить в Фитстенд опрос «какой велосипед нужен» с результатом, каталог 7 видов, справочник 8 узлов и виды Гибрид / MTB / Складной / «С мотором» в подборе размера.

**Architecture:** Статический сайт без сборки. Чистая логика (модель размера, отрисовка, подсчёт опроса, разбор адреса) лежит в отдельных JS-файлах. Они в браузере кладут свои объекты в `globalThis`, а в Node экспортируются через `module.exports`, поэтому тестируются через `node --test`. `index.html` остаётся фитстендом и выставляет `window.fitstand`. `guide.js` рисует новые экраны поверх фитстенда по адресу после `#`.

**Tech Stack:** HTML, CSS, ванильный JS (ES2020, обычные `<script>`), Node 22 `node:test` для тестов, Edge headless для скриншотов.

**Spec:** `docs/superpowers/specs/2026-11-03-guide-design.md`

- Все тексты интерфейса — на русском; кавычки «ёлочки», тире «—».

- Идентификаторы видов: `city`, `hybrid`, `gravel`, `mtb`, `road`, `folding`, `ebike`. Узлов: `frame`, `fork`, `brakes`, `drivetrain`, `wheels`, `cockpit`, `saddle`, `pedals`.
- Шаблон модуля для `model.js`, `draw.js`, `content.js`, `quiz.js`, `guide.js`:
