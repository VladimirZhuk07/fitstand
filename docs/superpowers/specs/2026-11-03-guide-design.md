# Фитстенд: опрос «какой велосипед», каталог видов и справочник узлов

Дата: 2026-11-03. Статус: черновик на просмотр.

## 1. Зачем

Сейчас Фитстенд подбирает размер рамы под рост для трёх видов (шоссе, грэвел, город), а вид человек выбирает сам. Новичок до покупки часто не знает, какой вид ему нужен. Опытный продавец велосипедов прислал отзыв: вопросы, которые он задаёт покупателю, правило подсчёта и список того, что нужно объяснить (виды, их плюсы и минусы, узлы велосипеда, с чего начать кататься).

Цель: человек за 1–2 минуты отвечает на 6 вопросов, понимает, какой вид велосипеда ему подходит и почему, видит подходящий размер и при желании узнаёт, из чего велосипед состоит.

Ограничения:

- без брендов и конкретных моделей;
- без сборки и фреймворков: статические файлы на GitHub Pages, PWA, работа офлайн;
- тексты компактные: помещаются на экран телефона, их вычитывает продавец.

## 2. Что входит

1. Опрос из 6 вопросов с подсчётом баллов и экраном результата.
2. Каталог 7 видов: городской, гибрид, грэвел, MTB, шоссе, складной, e-bike.
3. Справочник 8 узлов: рама, вилка и амортизация, тормоза, трансмиссия, колёса и покрышки, руль, седло и подседел, педали.
4. Фитстенд: два новых вида с подбором размера (гибрид, MTB), складной в упрощённом виде, переключатель «С мотором».
5. Скрипт, который собирает все тексты в читаемый документ для вычитки.

Не входит: фотографии, реальные таблицы геометрии брендов, переключатель темы, обёртка под Google Play.

## 3. Экраны и навигация

Фитстенд остаётся главным экраном. Новые экраны открываются поверх него во весь экран, у каждого есть кнопка «←». Адрес после `#` определяет экран, поэтому системная кнопка «Назад» на Android работает как ожидается.

| Адрес | Экран |
|---|---|
| пусто | фитстенд |
| `#quiz/1` … `#quiz/6` | вопрос N опроса |
| `#result` | результат опроса |
| `#types` | каталог видов |
| `#types/<вид>` | карточка вида |
| `#parts` | справочник узлов |
| `#parts/<узел>` | карточка узла |

Идентификаторы видов: `city`, `hybrid`, `gravel`, `mtb`, `road`, `folding`, `ebike`. Узлов: `frame`, `fork`, `brakes`, `drivetrain`, `wheels`, `cockpit`, `saddle`, `pedals`.

«←» делает шаг назад по истории. Если экран открыт прямой ссылкой (истории нет), «←» ведёт в фитстенд. Неизвестный адрес открывает фитстенд.

### 3.1 Входы из фитстенда

- Шапка: кнопка «Гид», открывает `#types`. На экранах каталога и справочника сверху переключатель «Виды / Узлы».
- Вкладка «Посадка», над выбором вида: плашка «Не знаю, какой велосипед — помогите выбрать», открывает `#quiz/1`.
- Выбор вида: сетка 3×2 (Шоссе, Грэвел, Город / Гибрид, MTB, Складной). Под ней ссылка «Об этом виде ›», открывает `#types/<текущий вид>`.
- Переключатель «С мотором» рядом с переключателями «Райдер» и «Размеры».

### 3.2 Опрос

Один вопрос на экран, сверху «N / 6» и полоса прогресса. Ответы — крупные кнопки. Нажатие сохраняет ответ и открывает следующий вопрос, после шестого открывается `#result`. Уже выбранный ответ отмечен. Ответы сохраняются, поэтому прерванный опрос можно продолжить.

### 3.3 Результат

Сверху вниз:

1. Схема велосипеда победившего вида (без райдера, под рост из фитстенда) и название, например «Гибрид» или «Городской с мотором».
2. «Почему»: 2–3 фразы-причины (см. 4.3).
3. «Ещё подойдёт»: второй вид, ссылка на его карточку (если есть).
4. «Что учесть»: заметки по ответам (если есть).
5. Плюсы и минусы вида.
6. «С чего начать»: программа катания из трёх шагов.
7. Кнопки: «Подобрать размер», «Пройти заново», «Все виды».

«Подобрать размер» ставит в фитстенде вид из результата и «С мотором», если он был в ответах, затем возвращает в фитстенд на вкладку «Итог». Результат опроса никогда не равен `ebike`: мотор — пометка к базовому виду. В карточке каталога `ebike` кнопка ставит `city` с мотором.

Если опрос не пройден до конца, `#result` открывает первый вопрос без ответа.

### 3.4 Каталог видов

Список из 7 карточек: мини-схема, название, одна строка. Карточка вида: большая схема, назначение (1–2 предложения), «кому подходит», 3–4 плюса, 3–4 минуса, программа катания, кнопка «Подобрать размер». E-bike рисуется как городской с мотором, текст объясняет, что мотор бывает у разных видов.

### 3.5 Справочник узлов

Список из 8 карточек: название и одна строка. Карточка узла: схема текущего вида фитстенда, где узел подсвечен, а остальное приглушено; 2–4 варианта узла, у каждого строка описания, плюсы и минусы.

### 4.2 Правила

- **Победитель:** вид с наибольшей суммой.
- **Ничья:** из равных выигрывает вид, получивший больше баллов от ответа на вопрос 3. Если ничья осталась, порядок такой: hybrid, city, gravel, road, mtb, folding.
- **Мотор:** ответ 6.5 добавляет к результату пометку «с мотором». Название: «<вид> с мотором». Складной с мотором допустим.
- **Совет про e-bike:** если пометки нет, но выбраны (2.1 или 2.4) и (6.1 или 6.4), в «Что учесть» появляется «присмотритесь к электровелосипеду».
- **Ещё подойдёт:** второй по сумме вид, если его сумма ≥ 75 % суммы победителя. Иначе блок не показывается.
- **Все ответы «нулевые»:** если сумма у всех видов 0 (это невозможно при 6 ответах, но проверяется), результат — hybrid.

### 4.3 Причины и заметки

У каждого ответа в данных есть короткая фраза-причина, например 1.2 → «катаетесь по грунтовым дорожкам». В «Почему» попадают фразы 2–3 ответов, давших победителю больше всего баллов (при равенстве — в порядке вопросов, ответы с 0 баллов не берутся).

Заметки «Что учесть» привязаны к ответам:

- 6.1 → нужны крепления под багажник и крылья;
- 6.4 → рама с креплением под детское кресло, не карбон, допустимая нагрузка на багажник;
- 4.5 → смотрите трейл/эндуро, а не кросс-кантри;
- 2.5 → проверьте вес и размер в сложенном виде;
- совет про e-bike (см. 4.2).

## 5. Фитстенд: новые виды

Все размеры — усреднённые значения без брендов, как и для существующих видов.

- **Гибрид:** прямой руль, посадка между грэвелом и городом. 6 размеров, колёса 700c (XS — 650b). Геометрия — смещение от базовой, как у грэвела и города.
- **MTB:** прямой широкий руль, короткий вынос, амортизационная вилка на схеме, широкие покрышки. Колёса 29" (XS и S — 27,5"). Те же 6 размеров XS–XXL, что у остальных видов, чтобы лесенка не менялась. Подбор: 178 см → M или L.
- **Складной:** колёса 20", один размер. Лесенка размеров заменяется надписью «один размер». В итоге остаются высота седла, длина шатунов и предупреждение, если рост вне 150–195 см. Метрики, которые для складного не имеют смысла (проставки, выход подседела над рамой), не показываются.
- **«С мотором»:** на схеме батарея на нижней трубе и мотор у каретки. Подбор размера не меняется.

Особые правила, которые сейчас записаны как `style==='city'` (длина шатунов, ширина руля, допустимый выход подседела), переносятся в свойства каждого вида.

## 6. Схема велосипеда

Отрисовка становится вызываемой для любого `<svg>` в двух режимах:

- **живой** (фитстенд): как сейчас, с райдером, анимацией и размерами;
- **статичный** (результат, каталог, справочник): без райдера, без размеров и анимации, шатуны в фиксированном положении, без `id` у элементов, чтобы не конфликтовать с фитстендом.

Опции: вид, «с мотором», подсвеченный узел. Каждая часть схемы помечается своим узлом (`data-part`). Подсветка: выбранный узел цветом акцента, остальное с пониженной непрозрачностью.

Новые элементы схемы:

- тормоза: дисковые (ротор и калипер) у гибрида, грэвела, MTB и e-bike; ободные у шоссе, города и складного;
- амортизационная вилка у MTB;
- батарея и мотор («с мотором»);
- маленькие колёса и шарнир у складного.

Статичная схема строится под текущий рост из фитстенда.

## 7. Файлы

| Файл | Что в нём |
|---|---|
| `index.html` | разметка, стили, интерфейс фитстенда, отрисовка |
| `model.js` | модель подбора размера (бывший блок MODEL START…END), без DOM |
| `draw.js` | отрисовка схемы велосипеда (живой и статичный режим, узлы), без DOM |
| `state.js` | чтение сохранения из localStorage с проверкой полей, без DOM |
| `content.js` | только данные: вопросы, ответы, баллы, фразы-причины, заметки, виды, узлы, программы |
| `quiz.js` | подсчёт результата по ответам, без DOM |
| `guide.js` | экраны опроса, результата, каталога, справочника и навигация по `#` |
| `tests/*.test.js` | автотесты `node --test` |
| `tools/content-review.mjs` | собирает тексты из `content.js` в `info/content-review.md` |

`model.js`, `draw.js`, `state.js`, `content.js` и `quiz.js` подключаются обычными `<script>` и кладут свои объекты в глобальную область, а в Node экспортируют их через `module.exports`. Так их можно тестировать без браузера.

`guide.js` общается с фитстендом через небольшой объект `window.fitstand`: прочитать текущие параметры, поставить вид и мотор, открыть вкладку, построить статичную схему.

`sw.js`: новые файлы добавляются в список кэша, версия поднимается до `fitstand-v2`. README дополняется разделом про тесты и скрипт вычитки.

## 8. Сохранение

Ключ localStorage остаётся `fitstand:v1`. Добавляются поля: `motor` (boolean) и `quiz` (массив из 6 номеров ответов или `null`). Поле `style` принимает новые значения `hybrid`, `mtb`, `folding`. Старые сохранения читаются как раньше, неизвестные значения игнорируются.

## 9. Ошибки и крайние случаи

- Повреждённый `quiz` в localStorage: опрос начинается заново.
- `#quiz/9`, `#types/xyz`, `#parts/xyz`: открывается список (`#quiz/1`, `#types`, `#parts`).
- Нет сети: всё работает из кэша, шрифты — системные запасные.
- Включено «уменьшить движение»: переходы между экранами без анимации.

## 10. Проверка

Автотесты (`node --test`):

- подсчёт: победитель, ничья по вопросу 3 и по порядку, мотор, совет про e-bike, «ещё подойдёт» на границе 75 %, ответ «не знаю», причины и заметки;
- целостность данных: у каждого ответа 6 баллов от 0 до 3 и фраза-причина; у каждого вида есть тексты, плюсы, минусы и 3 шага программы; у каждого узла 2–4 варианта;
- модель: для пресетов 160/178/195 см каждый вид, кроме складного, даёт размер, растущий с ростом; складной даёт один размер; значения конечные.

Ручная проверка на локальном сервере: ширина телефона (≈390 px) и десктоп, светлая и тёмная тема, кнопка «Назад» браузера, работа офлайн после первой загрузки, старое сохранение из версии 1.
