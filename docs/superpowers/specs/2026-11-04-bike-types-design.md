# Фитстенд: новые виды велосипедов и детская линейка

Дата: 2026-11-04. Статус: черновик на просмотр. Источник: второй отзыв продавца, раздел «Добавить виды велосипедов». Дизайн согласован в чате.

## 1. Зачем и границы

Каталог расширяется с 7 до 19 видов: MTB делится на хардтейл и двухподвес; добавляются циклокросс, трековый, трицикл, грузовой, BMX, специальные и пять детских видов. Опрос меняется только развилкой MTB.

Не входит: опрос «для ребёнка», реалистичные картинки (подпроект E), аксессуары (подпроект B). Без брендов.

## 2. Виды

Идентификаторы и группы (порядок внутри группы — порядок в каталоге):

| Группа `adult` «Взрослые» | Группа `kids` «Детские» | Группа `special` «Трюковые и специальные» |
|---|---|---|
| `city`, `hybrid`, `gravel`, `cx`, `road`, `track`, `mtb`, `fullsus`, `folding`, `ebike`, `trike`, `cargo` | `kidTrike`, `balance`, `kidTraining`, `kid`, `teen` | `bmx`, `special` |

Названия: `mtb` — «MTB хардтейл» (переименование), `fullsus` — «MTB двухподвес», `cx` — «Циклокросс», `track` — «Трековый», `trike` — «Трицикл», `cargo` — «Грузовой», `bmx` — «BMX», `special` — «Специальные», `kidTrike` — «Трёхколёсный», `balance` — «Беговел», `kidTraining` — «С поддерживающими колёсами», `kid` — «Детский двухколёсный», `teen` — «Подростковый».

### 2.1 Поля вида

Существующие поля (`name, short, purpose, forWhom, pros, cons, program`) — у всех. Новые:

| Поле | У кого | Содержание |
|---|---|---|
| `group` | все | `adult` / `kids` / `special` |
| `terrain` | `mtb`, `fullsus`, `cx`, `bmx` | «Для каких трасс» |
| `compare` | `cx` | «Чем отличается от шоссейного и чем похож» |
| `age` | детские | например «1–3 года» |
| `teach` | `balance`, `kidTraining`, `kid` | «Как учить» — 3–4 шага |
| `fear` | `kidTraining` | «Если ребёнок боится» — 3–4 совета |
| `variants` | `teen`, `kid`, `special` | варианты исполнения (амортвилка, передачи, тормоза; цирковые/трюковые) |
| `note` | `trike` | «Бывает электрическим» |
| `fitAs` | все | вид для «Подобрать размер»: `cx→gravel`, `track→road`, `trike→city`, `cargo→city`, `ebike→city` с мотором, `fullsus→fullsus`, у остальных взрослых — сам вид; у детских, `bmx`, `special` — `null` (кнопки нет) |

Тексты по отзыву: «полное описание» — `purpose` 2–4 предложения, `pros/cons` 3–5, `program` 3 шага. Для детских программа — как приучать ребёнка.

### 2.2 Таблица «рост ребёнка → колесо»

`CONTENT.kidsWheels`: 85–100 см → 12″, 95–110 → 14″, 105–120 → 16″, 115–135 → 20″, 130–150 → 24″. Показывается на каждой карточке детского вида с подсветкой строк, подходящих к его колёсам: `kidTrike` и `balance` — 12″; `kidTraining` — 12–16″; `kid` — 16–20″; `teen` — 24″.

## 3. Опрос: развилка MTB

Баллы по-прежнему у `mtb`. В `buildResult`, если вид варианта `mtb`, он заменяется на `fullsus`, когда выполнено одно из условий:

- `q4` = «Иногда прыгаю и катаюсь агрессивно»;
- `cushion` = «Критична, готов(а) на дополнительный вес»;
- отмечен блок «Спина» и `isOffroad`.

«Максимальный комфорт» при бездорожье — вид `fullsus`; оснастка `fullSusp` у видов `fullsus` не показывается (она в самом виде). «Проще и дешевле» для `fullsus` — `mtb` (хардтейл) без амортизации подседельного штыря.

## 4. Подбор размера

- `fullsus`: новый вид в модели — геометрия `mtb`, те же 6 размеров, `rearShock: true` для схемы. В фитстенде — кнопка «Двухподвес» в выборе вида (сетка 3×3 из 7 кнопок).
- Остальные новые виды в выборе вида не появляются; «Подобрать размер» на карточке открывает фитстенд с видом `fitAs`.

## 5. Схемы

Статичная схема каждого вида строится моделью по своему набору параметров (`STYLES` + один размер), со своим «манекеном» роста для детских и BMX. Новые элементы схемы, каждый с меткой `data-k`:

| Метка | Вид | Как выглядит |
|---|---|---|
| `rearShock` | `fullsus` | задний амортизатор между подседельной трубой и перьями, маятник |
| `noBrakes` | `track` | без тормозов и без защиты цепи |
| `trike` | `trike`, `kidTrike` | второе заднее колесо, смещённое и полупрозрачное |
| `cargoBox` | `cargo` | короб перед рулём над передним колесом |
| `noPedals` | `balance` | без шатунов, педалей, цепи и звезды |
| `trainingWheels` | `kidTraining` | два маленьких колеса у заднего |
| `frontPedals` | `kidTrike` | шатуны на оси переднего колеса, без цепи |
| `unicycle` | `special` | одноколёсный: колесо, штырь от оси к седлу, шатуны на оси |

Колёса: добавляются диаметры `12`, `14`, `16`, `24` (радиус по борту 101,5 / 127 / 152,5 / 253,5 мм).

## 6. Каталог

Экран «Виды велосипедов» — три раздела с заголовками групп. Карточка вида: схема, название, для детских — возраст рядом с названием. Экран вида — как сейчас плюс новые поля: «Для каких трасс», «Чем отличается от шоссейного и чем похож», «Возраст», «Как учить», «Если ребёнок боится», «Варианты», заметка трицикла, таблица колёс для детских. «Подобрать размер» — только при `fitAs`.

## 8. Проверка

Автотесты: целостность 19 видов и полей по таблице 2.1; группы покрывают все виды ровно один раз; `kidsWheels`; развилка `fullsus` по трём условиям и её отсутствие без них; «Проще и дешевле» для `fullsus` — `mtb`; модель даёт конечные числа для всех новых видов; разметка каждой схемы содержит свою метку и не содержит чужих; старые эталоны модели не меняются.

Между задачами — быстрые проверки в браузере: страница открывается без ошибок, каталог из трёх разделов, схемы всех 19 видов, опрос с MTB. Общее ревью — в конце, вместе с подпроектом B.
