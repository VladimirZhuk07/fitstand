# Фитстенд: аксессуары и их подбор

Дата: 2026-11-04. Статус: согласовано в чате. Источник: второй отзыв продавца, разделы с аксессуарами и «Как использовать в приложении».

## 1. Зачем и границы

Каталог ~65 аксессуаров в 10 группах и подбор 3–5 штук после опроса: сначала безопасность, потом комфорт и практичность, потом электроника; группировка по ситуациям; учёт травм; подсказки о совместимости; аксессуары в программе катания. Без брендов, без фото (подпроект E), без цен.

## 2. Данные (`content.js`)

`CONTENT.accGroups` — 10 групп в порядке отзыва: `safety` 🦺 «Безопасность и видимость», `repair` 🔧 «Ремонт в дороге», `theft` 🔒 «Защита от кражи», `cargo` 🎒 «Груз и туринг», `weather` 🌧️ «Погода и одежда», `comfort` 🪑 «Комфорт и посадка», `electronics` 📱 «Электроника и навигация», `care` 🧴 «Уход и хранение», `transport` 🚗 «Перевозка», `kids` 🧒 «Детские аксессуары». У группы — `sections: [{title?, ids}]`: у `safety` — «Обязательные» и «Дополнительные», у `repair` — «Минимальный набор» и «Дополнительные», у остальных — одна секция без заголовка.

`CONTENT.accessories[id]`:

| Поле | Обязательно | Содержание |
|---|---|---|
| `name` | да | название |
| `short` | да | до 70 символов |
| `text` | да | описание, 1–3 предложения |
| `kinds` | нет | `[{name, text}]` — виды (где продавец просил: шлемы, фонари, звонки, перчатки, очки, насосы, велосумки, бутылки, крылья, педали, велотуфли, велокомпьютеры, смазки, багажники, детские кресла, крепления на машину) |
| `choose` | нет | `[строка]` — «Как выбрать» (шлем, фонари, велотуфли, педали, детское кресло, детский шлем, одежда) |
| `check` | нет | «Проверьте совместимость» (подседельный штырь, багажник, педали, крылья, камера, детское кресло, крепления) |
| `weather` | нет | «Под какую погоду» (одежда) |
| `priority` | да | `1` безопасность, `2` комфорт и практичность, `3` электроника |
| `when` | да | `'always'` или список ситуаций (раздел 3) |
| `why` | да | короткое «зачем» для блока «Что взять» |

Позиции — все, перечисленные в отзыве, плюс одежда, которую продавец просил добавить (велошорты с памперсом, ветровка, тайтсы, зимние перчатки).

## 3. Ситуации

`accSituations(A, C)` возвращает множество ситуаций по ответам:

| Ситуация | Когда |
|---|---|
| `city` | `q1` = город или `q2` = до работы/магазина |
| `commute` | `q2` = до работы/магазина |
| `rain` | `commute` или `q6` = багажник и сумки |
| `touring` | `q2` = 50+ км или `q6` = багажник и сумки |
| `long` | `q2` = 2–4 часа или 50+ км |
| `offroad` | `isOffroad(A)` |
| `kids` | `q6` = детское кресло |
| `back` | отмечен блок «Спина» |
| `wrists` | в `upper1` запястья, туннельный синдром или «руки устают» |
| `knees` | отмечен блок «Колени» |

Заголовки ситуаций для экрана: `city` «Для города», `rain` «Для дождя», `touring` «Для туринга», `offroad` «Для бездорожья», `kids` «Для ребёнка», `back` «Для спины», `wrists` «Для рук», `knees` «Для коленей», `long` «Для длинных поездок». `commute` заголовка не имеет (внутренняя).

## 4. Подбор

`recommendAccessories(A, C)` → `{ top: [id], bySituation: [{id, title, ids}] }`:

- кандидаты — аксессуары с `when: 'always'` и те, у кого пересечение `when` с ситуациями не пусто;
- `top` — кандидаты по `priority` (1, 2, 3), внутри приоритета — `always` раньше, затем порядок в `accessories`; первые 5; если кандидатов меньше 3 — сколько есть;
- `bySituation` — для каждой ситуации с заголовком (в порядке таблицы 3) аксессуары с этой ситуацией в `when`; пустые не показываются;
- обязательные для всех: шлем, передний фонарь, задний фонарь (`when: 'always'`, `priority: 1`).

## 5. Экраны

- Меню: пункт «Аксессуары» после «Узлы велосипеда».
- `#acc` — группы с иконкой, заголовком и секциями; карточки: название и `short`.
- `#acc/<id>` — `text`, «Виды», «Как выбрать», «Под какую погоду», «Проверьте совместимость».
- Результат опроса: после карточек вариантов — блок «Что взять» (`top`: название и `why`, ссылка на карточку), затем «По ситуациям» (`bySituation`: заголовок и ссылки), ссылка «Все аксессуары».
- «С чего начать»: у первого шага строка «Перед первой поездкой: …» — названия из `top` через запятую, строчными.
- Экраны детских видов: блок «Что взять» — аксессуары группы `kids`.
- Неизвестный `#acc/<id>` открывает `#acc`.

## 6. Файлы

`content.js` (данные), `quiz.js` (`accSituations`, `recommendAccessories`), `guide.js` (экраны, маршруты `acc`, `accItem`), `index.html` (стили), `tools/content-review.mjs` (раздел «Аксессуары»), `sw.js` (`fitstand-v6`).

## 7. Проверка

Автотесты: целостность данных (каждая позиция ровно в одной секции, поля по таблице 2, `when` из списка ситуаций, `priority` 1–3, без брендов); ситуации по ответам; подбор: всем — шлем и фонари, длина 3–5, безопасность первой, багажник → багажник и сумки в `bySituation.touring`, запястья → грипсы, спина → амортштырь, детское кресло → детское кресло и детский шлем; маршруты `#acc`, `#acc/<id>`, неизвестный id. Браузер: меню → аксессуары, карточка шлема, результат опроса с «Что взять» и строкой в программе, детский вид с аксессуарами.
