# Фитстенд: сцена поездки на главной (этап 4а)

Дата: 2026-11-06. Статус: на просмотр. Источник: третий отзыв, пункт 3 («Анимация велосипедиста на главной должна быть более реалистична», подробное ТЗ). Этап 4а из 4а/4б: сцена и движение. 4б — объёмный райдер, одежда и полуреалистичная отрисовка велосипеда.

## 1. Зачем и что

Главная — экран подбора посадки: схема велосипеда и райдер по пропорциям пользователя, педали крутятся (каденс 40). Продавец просит живую сцену: спокойная поездка, многослойный фон с параллаксом, правильная физика колёс, естественный каденс, микроколебания руля, мягкий свет, бесшовный цикл 8–10 с.

Решения, принятые с пользователем:

- **Едет — сцена, пауза — чертёж.** Пока крутятся педали: фон, свет, движение, без сетки и линий размеров. На паузе: фон уходит, сетка и размеры (если включён «Размеры») возвращаются. При `prefers-reduced-motion` — сразу чертёж (как сейчас — на паузе).
- **Фон рисуется в коде (SVG)**, ничего не генерируется; тёмная тема — вечерняя версия.
- Посадку и цифры по-прежнему считает модель; вид по умолчанию — гибрид (уже сделано).

Не входит (4б): объёмное тело, одежда, шлем с ремешком, кроссовки, кисти, колыхание одежды, объём и блики велосипеда.

## 2. Что видит человек

### 2.1 Сцена (едет)

- Небо — вертикальный градиент тёплых тонов; дальний план — мягкие холмы в дымке; средний — силуэты деревьев и кустов; ближний — трава у дороги и столбики; дорога — полоса под колёсами с мелкой фактурой.
- Параллакс: дальний слой едва движется, средний — быстрее, ближний — быстрее дороги (ближе к камере), фактура дороги — ровно со скоростью колеса.
- «Размытие» без фильтров: дальний и средний планы светлее и мягче (прозрачность, дымка-градиент поверх), ближний — крупные полупрозрачные пятна.
- Свет: тёплый градиент сбоку поверх неба (статичный); тень под велосипедом — мягкий эллипс, слегка меняется с подпрыгиванием.
- Колёса на ходу: спицы почти прозрачны, поверх — полупрозрачный диск; обод чёткий; маленькая метка ниппеля у обода вращается с колесом.
- Тёмная тема: сумерки — тёмно-синее небо, силуэты темнее, та же композиция.

### 2.2 Движение (цикл 9 с, бесшовный)

| Что | Значение |
|---|---|
| Шатуны | 12 оборотов за цикл — каденс 80 |
| Колёса | целое число оборотов за цикл `N = round(v₀·9 / (2πR))`, `v₀ = 6 м/с` (≈ 22 км/ч); скорость дороги `v = N·2πR / 9` — дорога точно совпадает с колесом |
| Корпус | поворот вокруг таза ±1,2° в такт нажатиям (24 за цикл) |
| Голова | компенсирует поворот корпуса (держится ровно) |
| Дыхание | грудь (плечо) поднимается до 6 мм, 3 вдоха за цикл |
| Руль | нерегулярно ±1,35° максимум: сумма синусов с 2, 5 и 7 периодами за цикл; руки следуют за грипсами (локоть пересчитывается) |
| Подпрыгивание | весь велосипед с райдером по вертикали до ±3 мм: сумма синусов с 13 и 29 периодами за цикл |

Все колебания — целое число периодов за цикл, поэтому стык цикла не виден, а «нерегулярность» получается из несоизмеримых на глаз частот.

### 2.3 Чертёж (пауза)

Как сейчас: сетка, земля-линия, тень, линии размеров (если включены), райдер в позе текущего кадра. Переход сцена ↔ чертёж — плавный (opacity 0,3 с).

## 3. Как устроено

### 3.1 `ride.js` (новый модуль, паттерн globalThis/module.exports)

- `RIDE = { PERIOD: 9, CRANK_REVS: 12, SPEED: 6000 }` (мм/с).
- `ridePose(t, wheelR) → { crank, wheel, ground, torso, breath, bar, bounce }`:
  - `t` по модулю `PERIOD`; `crank`, `wheel` — градусы поворота (шатун вперёд по ходу, колесо по ходу), `ground` — пройденный путь в мм (`v·t`), `torso`, `bar` — градусы, `breath`, `bounce` — мм.
- `LAYERS = [{ id: 'far', k: 0.06 }, { id: 'mid', k: 0.35 }, { id: 'near', k: 1.3 }, { id: 'road', k: 1 }]` и `layerShift(id, t, wheelR) → { x, tile }`: ширина плитки слоя `tile = v·PERIOD·k / n` (целое `n` подобрано так, чтобы плитка была 2500–4500 мм), сдвиг `x = −(v·t·k) mod tile`. За цикл слой сдвигается ровно на `n` плиток.
- `rideBgMarkup(bounds) → string` — `<g id="rideBg">`: `<defs>` с узорами слоёв (ширина узора — базовая, масштабируется `patternTransform`), прямоугольники неба, слоёв, дороги, дымки, света; координаты в мм, как у схемы (`y` вниз в разметке, земля — `ground` из `geomPts`). Цвета — CSS-переменные сцены.
- `applyRide(svg, pose, shifts)` — ставит `patternTransform` слоёв.

### 3.2 `draw.js`

В живой разметке (`live`):

- верх райдера подвижен: элементы с `id` — `uHip`, `uTorso`, `uNeck`, `uUpper`, `uFore`, `uHand`, `uHead`, `uHelmet`; новая функция `upperAt(g, hip, hand, pose) → { shoulder, elbow, hand, head }` — плечо = поворот `shoulder₀ − hip` на `torso` + `breath` вверх; кисть — грипса, повёрнутая на `bar` вокруг выноса `ck.C`; локоть — `ik2`; голова — `head₀` со сдвигом плеча, без поворота;
- руль (`part('cockpit')`) получает `id="cockpitG"` — для поворота на `bar` вокруг `ck.C`;
- у колёс: спицы в `<g class="spokes">`, диск `<circle class="blur-disc">` и метка `<circle class="valve">` внутри вращаемой группы;
- сетка — `<rect class="grid-bg">`.

Статическая разметка (каталог, результат) не меняется.

### 3.3 `index.html`

- `#bike` получает класс `riding`, пока `state.playing`; CSS: в `riding` скрыты `.grid-bg`, `.dims`, `.ground` (вместо неё дорога), видны `#rideBg`, `.blur-disc`; спицы прозрачнее. Без `riding` — наоборот. Переход — `opacity .3s`.
- Цикл анимации: время сцены `rideT` растёт на `dt` (шаг не больше 0,05 с) только при `playing`; поза — `ridePose(rideT, g.wheelR)`; ноги — `legAt(g, hip, crankAngle)`, колёса — `wheel`, верх — `upperAt`, руль — `cockpitG`, подпрыгивание — `transform` у `#scene`, фон — `applyRide`.
- `#rideBg` перестраивается в `rebuild()` (границы меняются вместе с `viewBox`), ставится первым в `#bike`.
- CSS-переменные сцены: `--sky-top`, `--sky-bottom`, `--hill`, `--tree`, `--grass`, `--road`, `--haze`, `--sun` — светлые и тёмные значения.
- `<script src="./ride.js">` до основного скрипта; `sw.js`: `./ride.js` в `CORE`, `fitstand-v12`.

## 4. Тесты

- `ridePose`:
  - за цикл ровно 12 оборотов шатунов и целое число оборотов колеса (для колёс 700c, 26″, 20″, 16″);
  - дорога совпадает с колесом: `ground(t) = wheel(t)/360·2πR` (погрешность < 0,5 мм);
  - стык: поза в `t = 9 − ε` и `t = 0` отличается не больше чем на шаг кадра (углы по модулю 360);
  - `|torso| ≤ 2`, `|bar| ≤ 1.5`, `0 ≤ breath ≤ 6`, `|bounce| ≤ 3` на всём цикле;
  - руль нерегулярен: на цикле больше 4 локальных максимумов разной высоты.
- `layerShift`: для каждого слоя `v·PERIOD·k / tile` — целое; `tile` в 2500–4500 мм; сдвиг в `t` и `t + 9` совпадает; скорость `road` равна скорости колеса, `near` больше, `mid` и `far` меньше.
- `draw`: живая разметка содержит `id` верха райдера, `cockpitG`, `.spokes`, `.blur-disc`, `.valve`, `.grid-bg`; статическая — нет; `upperAt` при нулевой позе совпадает с `upperOf` (плечо, кисть, голова — до 0,5 мм); кисть всегда на расстоянии ≤ длины руки от плеча.
- `index.html`: правила `#bike.riding` для `.grid-bg`, `.dims`, `#rideBg`; `ride.js` подключён до основного скрипта; `sw`: v12 и `ride.js` в `CORE`.
- Браузер: сцена на ходу и чертёж на паузе; телефон и десктоп; светлая и тёмная; «уменьшить движение» — чертёж; плавность (обновлений в секунду не меньше, чем сейчас); смена вида велосипеда и роста на ходу — сцена перестраивается без ошибок.
