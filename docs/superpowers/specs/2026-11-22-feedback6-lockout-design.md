# Анимация блокировки и полный набор блоков в «Вилка и амортизация» (отзыв 6, R4 + R5)

Источник: `info/Feedback 6/Решения/Фитстенд - требования по отзыву 6.docx` (R4, R5, таблица Б); образец продавца `info/Feedback 6/ref-air-fork-lockout.png`. Контекст: `2026-11-11-suspension-design.md` (страницы вилок и схемы из отзыва 5).

## Что понято
Продавец хочет, чтобы на страницах пружинной вилки, воздушной вилки и заднего амортизатора было видно, как работает блокировка: разрез, который проходит 4 шага — сжатие, отбой, включение блокировки, удар при закрытой блокировке. Образец — техническая иллюстрация в разрезе. Под анимацией — одинаковый полный набор блоков у всех трёх узлов. Ответы продавца: амортизатору нужно всё, как у вилок; видео только на главной, поэтому здесь не видео.

Решения пользователя: рисуем сами в SVG (не картинки нейросети); одна панель разреза плавно проходит 4 шага; управление — пауза и кнопки шагов.

## Что уже есть (не переделываем)
- Страницы узлов (`guide.js` `detailView`): виды с фото (по 3), описание, плюсы и минусы, «Для каких трасс», блоки `usage` (рекомендации, зачем нужна блокировка, настройки, поломки, ремонт), у воздушной — `breaks`.
- Статичные схемы `img/details/<id>-schema.svg` (4 панели, русские подписи) — остаются ссылкой «Схема целиком».
- Анимация с кочкой и подъёмом на общей странице «Вилка и амортизация» (`forkAnim.js`) — без изменений.
- `detailView` уже рисует блок «Уход» из поля `care`.

## 1. Модуль `lockAnim.js` (новый)
UMD-модуль как `forkAnim.js`: чистые функции тестируются в Node, функции страницы работают с DOM.

### Сценарий цикла (общий для трёх узлов)
`LOCK_PERIOD = 10` с. `lockState(t) -> {step, c, lever, valve, flow, impact}`:

| Время, с | step | c (ход, 0…1) | lever (0 = открыто, 1 = закрыто) | valve (0 = открыт, 1 = закрыт) | flow | impact |
|---|---|---|---|---|---|---|
| 0–3 | 1 | 0 → 0.7, плавно (ease-in-out) | 0 | 0 | `+1` (вниз/внутрь) | 0 |
| 3–5 | 2 | 0.7 → 0, плавно | 0 | 0 | `-1` (обратно) | 0 |
| 5–7 | 3 | 0 | 0 → 1, плавно | следует за рычагом с задержкой 0.3 с | 0 | 0 |
| 7–9.4 | 4 | не больше 0.04 (вздрагивает на ударе) | 1 | 1 | 0 | стрелка: подлетает 7–7.8, отскакивает 7.8–8.6, исчезает к 9.4 |
| 9.4–10 | 4 | 0 | 1 → 0, быстро | 1 → 0 | 0 | 0 |

- Цвет индикатора рычага: зелёный при `lever < 0.5`, красный при `lever >= 0.5`.
- Цикл замыкается без скачка: `lockState(9.999)` и `lockState(0)` отличаются не больше чем на 0.01 по каждому числу.
- `lockState(t)` для любого `t` (в том числе отрицательного и больше периода) берёт `t` по модулю периода.

### Рисунок (`lockMarkup(kind) -> string`, `kind`: `'spring' | 'air' | 'shock'`)
Одна панель разреза, viewBox `0 0 800 900` (вилки) и `0 0 1000 600` (амортизатор). Стиль — как у схем отзыва 5: металл с градиентами, тёмная полость, янтарное масло, русские подписи. Подписи — `<text>` с классом `la-label`.
- **Пружинная вилка:** корона, верхние и нижние ноги, стальная пружина (витки, сближаются при сжатии), масляный картридж с клапаном и иглой, сальник, рычаг блокировки на короне с индикатором.
- **Воздушная вилка:** то же, вместо пружины — позитивная камера (сверху, голубые частицы), поршень, негативная камера (снизу, оранжевые частицы), байпас; масло янтарное, чтобы не путать с оранжевой камерой.
- **Амортизатор:** горизонтальный корпус с двумя проушинами, воздушная банка, шток, масляный клапан с иглой, рычаг на корпусе с индикатором.
- Подписи: корона / проушина, пружина / позитивная камера / негативная камера, поршень, байпас, демпфер, клапан, игла, рычаг блокировки, сальник, шток.
- У каждого элемента, который двигается, постоянный `id` с префиксом `la-`; число и `id` элементов не зависят от шага.

### Кадр (`lockPose(kind, state) -> [{id, attrs}]`)
Список изменений атрибутов для кадра: смещение нижней ноги / штока на `c`, точки пружины, плотность и положение частиц (позитивная сгущается при сжатии, часть частиц идёт через байпас в негативную; при `valve = 1` частицы стоят), стрелки потока масла (видимы при `flow ≠ 0`, направление по знаку), поворот рычага, класс индикатора (`la-open` / `la-closed`), игла (опущена при `valve = 1`), крест на клапане (виден при `valve = 1` и `impact > 0`), стрелка удара. Частицы двигаются детерминированно (без `Math.random` между кадрами), цикл бесшовный.

### Блок страницы (`lockBlock(kind) -> string`, `startLockAnim(el, kind)`)
- Разметка: SVG, подпись шага (`<p class="la-caption" aria-live="polite">`), кнопки «1 Сжатие», «2 Отбой», «3 Блокировка», «4 Удар» (`role="radio"`, текущий шаг отмечен) и кнопка «Пауза» / «Пуск».
- Подписи шагов: «Блокировка открыта: вилка сжимается на кочке, масло свободно проходит через клапан», «Отбой: вилка возвращается, масло течёт обратно», «Рычаг повернули: индикатор красный, игла перекрывает масло», «Удар при закрытой блокировке: масло не проходит, вилка не сжимается». Для амортизатора слово «вилка» заменяется на «амортизатор».
- Кнопка шага переводит время на начало шага (для шага 4 — на 7.8 с, момент удара) и ставит на паузу.
- `prefers-reduced-motion: reduce`: цикл не запускается, показан шаг 4 (момент удара), кнопки работают.
- Цикл останавливается, когда блок уходит со страницы (страница закрыта или открыта другая); новый запуск не плодит второй таймер.

## 2. Страницы узлов (`guide.js`, `content.js`)
- В `detailView` раздел «Принцип работы» для деталей с `lock` (`'spring' | 'air' | 'shock'`) рисует `lockBlock(d.lock)`, а под ним — ссылку «Схема целиком» на прежнюю схему (`schemaImg(id)`). Детали без `lock` — как сейчас.
- После отрисовки страницы детали `guide.js` вызывает `startLockAnim` (как сейчас `startForkAnim` для страницы узла).
- `content.js`: у `springFork` — `lock:'spring'`, у `airFork` — `lock:'air'`, у `rearShock` — `lock:'shock'`.
- Порядок разделов на этих трёх страницах: «Принцип работы» → «Виды» → «Как пользоваться блокировкой» → «Уход» → «Поломки и как устранить» → «Как использовать» (рекомендации и настройки).
- Данные трёх деталей:
  - `lockout: [строки]` — «Как пользоваться блокировкой»: зачем и как. Переносится из блока `usage` «Зачем нужна блокировка» и дополняется «как»: где рычаг, когда включать (подъём, асфальт), когда выключать (спуск, кочки), не прыгать с закрытой блокировкой.
  - `care: [строки]` — «Уход»: новый блок, 4–6 пунктов на узел (протирать ноги / шток, проверять давление или преднатяг, смазка сальников, сервис масла по сроку, хранение).
  - `breaks: [{name, text, fix}]` — «Поломки и как устранить»: объединение прежних «Возможные поломки» / `breaks` и «Ремонт» / «Ремонт своими руками»: признак, как избежать, как устранить (сам или в мастерской).
  - Из `usage` убираются перенесённые подблоки; остаются «Рекомендации по использованию» и «Настройки».
- В `guide.js` раздел `breaks` выводит `fix`, если он есть; заголовок — «Поломки и как устранить».
- Тексты — по-русски, коротко, без марок; смысл прежних текстов сохраняется.

## 3. Прочее
- `index.html`: `<script src="./lockAnim.js">` перед `guide.js`; стили блока (`.la-*`) для светлой и тёмной темы. Цвета частиц и индикатора: голубой `#5EB8F0`, оранжевый `#F29A4A`, масло `#D9A441`, зелёный `#3FAE5C`, красный `#D9473F`.
- `sw.js`: `./lockAnim.js` в списке файлов офлайн-кэша. Версия кэша поднимается при слиянии в main.

## Тесты
- `lockState`: шаг на границах 0, 3, 5, 7, 9.4, 10; `c` на шаге 4 не больше 0.04; стык цикла (9.999 и 0 — разница не больше 0.01); `t` по модулю периода (−1 и 9, 23 и 3).
- Индикатор: для всех `t` с шагом 0.05 класс индикатора соответствует `lever` (`< 0.5` → открыто).
- `lockMarkup`: у каждого `kind` есть рычаг, индикатор, клапан, игла, подписи; у `air` — частицы двух цветов и байпас; у `shock` — две проушины; нет `Math.random` в коде модуля.
- `lockPose`: для всех `t` все `id` из списка есть в разметке; при `valve = 1` частицы не двигаются между соседними кадрами; при сжатии позитивная камера сгущается (среднее расстояние между частицами уменьшается).
- `lockBlock`: 4 кнопки шагов и кнопка паузы; подписи шагов для амортизатора говорят «амортизатор».
- Контент: у трёх деталей есть `lock`, `lockout`, `care` (4–6 пунктов), `breaks` с `fix` у каждого пункта; в `usage` больше нет подблоков про блокировку и ремонт; проверка на марки проходит.
- `guide.js`: на странице детали с `lock` порядок разделов как выше; есть ссылка «Схема целиком».
- `sw.js` содержит `./lockAnim.js`.
- Вручную: три страницы в светлой и тёмной теме, весь цикл, кнопки шагов, пауза, выключенная анимация в системе.
