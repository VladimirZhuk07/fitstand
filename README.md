# Фитстенд

Подбор велосипеда под рост и пропорции райдера: размер рамы, высота седла, вынос, проставки, угол спины и колена. Опрос из 6 вопросов подсказывает, какой вид велосипеда нужен; гид рассказывает о видах и узлах. Работает как устанавливаемое приложение (PWA) и офлайн.

## Состав

| Файл | Зачем |
|---|---|
| `index.html` | разметка, стили и интерфейс фитстенда |
| `model.js` | модель подбора размера рамы и посадки |
| `draw.js` | схема велосипеда сбоку (фитстенд, гид, подсветка узлов) |
| `state.js` | чтение сохранённых параметров |
| `content.js` | все тексты: опрос и баллы, виды, узлы, программы катания |
| `quiz.js` | подсчёт результата опроса |
| `guide.js` | экраны опроса, результата, каталога и справочника |
| `tests/` | автотесты (`node --test`) |
| `tools/content-review.mjs` | выгрузка текстов на вычитку |
| `manifest.webmanifest` | название, иконки и полноэкранный режим для «Установить приложение» |
| `sw.js` | service worker: кэш для работы без интернета |
| `icons/` | иконки 32, 180, 192, 512 и маскируемая 512 |
| `.nojekyll` | чтобы GitHub Pages отдавал файлы как есть |

## Публикация на GitHub Pages

1. На **личном** аккаунте GitHub создайте **публичный** репозиторий, например `fitstand`.
   Pages на бесплатном аккаунте работает только с публичными репозиториями.
2. Залейте файлы в корень репозитория:
   - через сайт: **Add file → Upload files**, перетащите всё содержимое папки (включая папку `icons`), **Commit changes**;
   - или из терминала:
     ```bash
     cd fitstand-pwa
     git init -b main
     git add .
     git commit -m "Fitstand PWA"
     git remote add origin https://github.com/<логин>/fitstand.git
     git push -u origin main
     ```
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`, **Save**.
4. Через 1–2 минуты сайт будет по адресу `https://<логин>.github.io/fitstand/`.

## Установка на Android

1. Откройте адрес в **Chrome** на телефоне.
2. Нажмите плашку **«Установить приложение»** или **⋮ → Установить приложение** (в старых версиях — «Добавить на главный экран»).
3. Иконка «Фитстенд» появится на рабочем столе. Приложение открывается во весь экран и работает без сети. Последние введённые параметры сохраняются.

На iPhone: Safari → «Поделиться» → «На экран „Домой“».

## Как выпустить обновление

1. Измените файлы.
2. В `sw.js` увеличьте версию (`fitstand-v2` → `fitstand-v3`). Новый файл добавьте в список `CORE`, иначе он не будет работать офлайн (это проверяет `node --test`).
3. Закоммитьте и запушьте. Телефоны подхватят новую версию при следующем запуске (иногда нужен второй запуск).

## Проверка локально

Service worker работает только по HTTPS или на `localhost`:

```bash
cd fitstand-pwa
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Тесты

Логика (модель подбора, подсчёт опроса, тексты) проверяется без браузера, нужен Node 18+:

```bash
node --test
```

## Тексты на вычитку

Все тексты живут в `content.js`. Чтобы собрать их в один читаемый документ:

```bash
node tools/content-review.mjs
# создаст info/content-review.md (папка info не попадает в git)
```

## Картинки аксессуаров и узлов

1. `node tools/make-image-prompts.js` — собирает промпты в `info/image-prompts.md` (по одному на каждый аксессуар и вариант узла).
2. Генерация (например, в Cursor) сохраняет PNG в `img/raw/` (папка не попадает в git).
3. `python tools/convert-images.py` (нужен Pillow) — сжимает в WebP 512×512: `img/acc/<id>.webp`, `img/parts/<узел>-<n>.webp`.

`node --test` проверяет, что картинка есть у каждой позиции и весит не больше 120 КБ.
